# Native anomaly model folders

The anomalib package is installed in `.venv`, and the native model backbones have been warmed in the local Hugging Face cache.

These folders are reserved for copper-tube-trained checkpoints:

- `patchcore/model.ckpt`
- `efficientad/model.ckpt`
- `fastflow/model.ckpt`

Do not copy public MVTec demo checkpoints here unless you intentionally want a non-copper demo baseline.
