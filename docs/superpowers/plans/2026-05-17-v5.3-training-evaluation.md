# V5.3 Training & Evaluation Desktop UI — Implementation Plan

> **For agentic workers:** Use subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Add YOLO training, model inference, evaluation (mAP/PR/confusion), model version management, and multi-model comparison to the desktop app — all reusing existing core/metrics.py, core/matcher.py, core/confusion.py, model_runners/, and phase4 trainers/.

**Architecture:** TrainingWorker wraps YOLOTrainer from phase4 in QThread, capturing ultralytics stdout as log lines. InferenceWorker wraps model_runners for batch inference. Evaluation reuses core/metrics.py (mAP) and core/confusion.py. DefectOverlayView extends ImageViewer with bbox overlay using existing src/visualization/draw_boxes.py.

**Tech Stack:** PySide6, ultralytics, matplotlib (for PR/confusion charts), core/ (existing)

## Tasks

### Task Group A: Backend (DB + trainers + workers)

#### Task A1: Extend DB + TrainingJob + ModelVersion models

Modify `core/storage.py` init_db() — add tables:

```sql
CREATE TABLE IF NOT EXISTS training_jobs (
    job_id TEXT PRIMARY KEY,
    project_id TEXT NOT NULL,
    spec_id TEXT NOT NULL,
    dataset_path TEXT NOT NULL DEFAULT '',
    job_name TEXT NOT NULL,
    model_family TEXT NOT NULL DEFAULT 'yolo',
    base_model TEXT NOT NULL DEFAULT 'yolov8n.pt',
    task_type TEXT NOT NULL DEFAULT 'detection',
    training_config TEXT NOT NULL DEFAULT '{}',
    status TEXT NOT NULL DEFAULT 'created',
    start_time TEXT,
    end_time TEXT,
    output_dir TEXT,
    best_model_path TEXT,
    last_model_path TEXT,
    metrics TEXT,
    notes TEXT,
    created_at TEXT NOT NULL DEFAULT (datetime('now', 'localtime')),
    updated_at TEXT NOT NULL DEFAULT (datetime('now', 'localtime')),
    FOREIGN KEY (project_id) REFERENCES projects(project_id)
);

CREATE TABLE IF NOT EXISTS model_versions (
    model_id TEXT PRIMARY KEY,
    project_id TEXT NOT NULL,
    training_job_id TEXT,
    model_name TEXT NOT NULL,
    model_type TEXT NOT NULL DEFAULT 'yolo',
    model_path TEXT NOT NULL DEFAULT '',
    base_model TEXT,
    class_mapping TEXT NOT NULL DEFAULT '{}',
    metrics TEXT,
    status TEXT NOT NULL DEFAULT 'created',
    created_at TEXT NOT NULL DEFAULT (datetime('now', 'localtime')),
    updated_at TEXT NOT NULL DEFAULT (datetime('now', 'localtime')),
    notes TEXT,
    FOREIGN KEY (project_id) REFERENCES projects(project_id),
    FOREIGN KEY (training_job_id) REFERENCES training_jobs(job_id)
);
```

Create `core/training_job.py` — TrainingJob dataclass with: job_id, project_id, spec_id, dataset_path, job_name, model_family, base_model, task_type, training_config (JSON str), status, start_time, end_time, output_dir, best_model_path, last_model_path, metrics, notes, created_at, updated_at. CRUD functions: create/list/get/update/delete.

Create `core/model_version.py` — ModelVersion dataclass with: model_id, project_id, training_job_id, model_name, model_type, model_path, base_model, class_mapping (JSON str), metrics, status, created_at, updated_at, notes. CRUD functions: create/list/get/update/delete.

Status values: created, queued, running, completed, failed, candidate, archived.

#### Task A2: Copy trainers from phase4

Copy these files from `phase4_v0_4_platform/trainers/` to `trainers/`:
- `__init__.py` — auto-import yolo_trainer, patchcore_trainer
- `base.py` — BaseTrainer ABC
- `registry.py` — Trainer registry with @register decorator

IMPORTANT: Fix import paths. The phase4 code imports `from core.storage import ...` — these work as-is since our main project also has core/storage.py. No changes needed to import paths.

#### Task A3: TrainingWorker + InferenceWorker

Create `desktop_app/workers/training_worker.py` — wraps YOLOTrainer in BaseWorker:
- Takes job_id, calls trainers.registry.get_trainer("yolo")
- Runs prepare() → train(progress_callback) → collect_results()
- Captures ultralytics stdout/stderr via sys.stdout redirection, emits log lines
- Emits progress, message (log lines), finished with best_model_path
- On completion: updates training_job status, creates model_version

Create `desktop_app/workers/inference_worker.py` — wraps model_runners in BaseWorker:
- Takes model_path, image_paths list, class_names, config dict
- Creates YoloModelRunner, loads model, runs predict_batch with progress callback
- Emits progress(current, total), returns list[ImagePrediction]
- Handles model load/inference exceptions
